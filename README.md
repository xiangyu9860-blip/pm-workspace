# AI 产品经理工作台

> 右侧输入工作内容，AI 自动拆解为子任务展示在左侧看板；支持手动编辑、一键生成日报/周报；内置自我进化学习，越用越懂你。

## 功能

- **AI 智能拆解** — 输入工作描述，自动识别场景（技术接入 / 需求分析 / 原型设计 / 数据分析 / 上线发布 / 竞品分析 / 会议协调 / 测试验收 / 项目协调），按时间切片拆解多任务
- **看板管理** — 待办 / 进行中 / 已完成 三列拖拽，支持手动增删改
- **一键日报 / 周报** — 基于已完成任务自动生成，复制即用
- **自我进化** — 记录你对 AI 拆解结果的调整逻辑（优先级偏好、分类偏好、日期偏好、命名风格），累计 2 次后自动应用，越用越准
- **云端同步** — 数据存储在资料库云端，多设备同步

## 技术栈

单文件 HTML 应用，无外部依赖，可直接在浏览器打开运行。

| 模块 | 说明 |
|------|------|
| 加权评分分类 | 每个场景含多个带权重关键词，按总分命中 |
| 时间切片拆解 | 识别"今天/明天/后天"等时间标记，分别拆解 |
| 学习引擎 | localStorage 存储用户调整模式，自动应用 |

## 在线使用

打开 `index.html` 即可运行，或在 GitHub Pages 访问在线版。
